> анализ рынка edTech РФ 2024–2026, общий UX-паттерн сегмента.

## 2. Тренды дизайна 2024–2026

### 2.1 Цветовые схемы
- **Господствующий тренд:** тёмно-синие/тёмно-серые «корпоративные» фоны с
  одним ярким акцентом. ANO DPO, Академия ДПО и «Профи» используют
  тёмно-синий (#1B2A4A…#0E1A2B) + белый текст + акцент
  (золотой/оранжевый/бирюзовый).
- «Специалист» — синий (#1A5C9E) + белый + красный акцент (классика
  IT-обучения).
- Чёрно-золотая премиальная пара (как у финансовых/MBA-программ) набирает
  популярность в сегменте ДПО «премиум» — выделяет лицензию и статус.
- Использование градиентов (синий→более тёмный синий) в hero-блоках вместо
  плоских заливок; мягкие радиальные «свечения» позади контента.

### 2.2 Шрифты
- Заголовки — гротески с широкими пропорциями (Montserrat, Manrope, Unbounded)
  либо классические антиквы (Playfair Display) для премиальных программ.
- Основной текст — Inter, Manrope, Golos Text, PT Sans (поддержка кириллицы
  обязана быть полной — это критично для РФ).
- Вектор на крупные заголовки (48–72px десктоп) и увеличенный межстрочный
  интервал (1.5–1.6) для читабельности с мобильного.

### 2.3 Структура страницы
Типовой «скелет» лендинга ДПО (встречается у 4 из 5):
1. Шапка: логотип + телефон + кнопка «Записаться/Заявка».
2. Hero: заголовок УТП + подзаголовок + форма/кнопка CTA + бейджи
   (лицензия, ФИС ФРДО, отзывов, выпускников).
3. Блоки «направления» (вкладки/табы по типам программ).
4. Преимущества (лицензия, преподаватели, документ гособразца, доставка).
5. Популярные курсы — карточки с ценой, длительностью, форматом.
6. Отзывы (слайдер) + логотипы партнёров/заказчиков.
7. FAQ-аккордеон.
8. Контакты + карта + форма.

## 3. Анимации и интерактивные элементы

| Элемент | Где встречается | Оценка |
|---------|-----------------|--------|
| Hover-подсветка карточек курса | ANO DPO, Академия ДПО, Профи | Базовый уровень, обязателен |
| Слайдер отзывов | МФЮА, Специалист, Академия ДПО | Используется Swiper/Slick |
| Бегущая строка логотипов | Академия ДПО, МФЮА | Бесконечный marquee партнёров |
| Accordion FAQ | ANO DPO, Профи | Чистый JS, без библиотек |
| Появление при скролле (fade/slide) | Все 5 | ScrollTrigger/GSAP либо AOS |
| Парсеклы/частицы в фоне | Редко (Специалист, премиум-блоки МФЮА) | Лёгкие, не нагружают LCP |
| 3D-tilt карточек | Премиальные программы MBA | GSAP + CSS perspective |
| Липкая шапка (sticky header) | Все 5 | Обязательный паттерн |
| Анимированный счётчик цифр | ANO DPO, Академия ДПО | «15 000 выпускников», «12 лет» |
| Чат-виджет / обратный звонок | Все 5 | B2B-конверсия |

**Вывод:** рынок использует анимации умеренно — приоритет за скоростью и
доверием. Сложные 3D-эффекты уместны только в премиальных блоках (MBA,
лицензия) и не должны вредить LCP.

## 4. Лучшие практики по сегментам

### B2C (физлица — рабочие профессии, переподготовка)
- Явная цена и длительность на карточке курса.
- «Документ гособразца», «внесение в ФИС ФРДО» как триггер доверия.
- Рассрочка/скидки, быстрое оформление заявки (1 поле — телефон).
- Отзывы с фото и специальностью.

### B2B (юрлица — корпоративное обучение, охрана труда, ПТМ)
- Калькулятор стоимости группы, спецпредложение при коллективной заявке
  (как у Академии ДПО — «спеццены при коллективной заявке»).
- Раздел «Корпоративным клиентам» с менеджером и счётом-договором.
- Логотипы заказчиков (Газпром, нефтегаз, госструктуры).

### B2G (госзаказчики — министерства, ведомства, МУПы)
- Блок «гослицензия», № лицензии, наименование органа (Рособрнадзор).
- Упоминание 44-ФЗ/223-ФЗ, опыт работы с госконтрактами.
- Заключение СЭЗ, выписки из реестра аккредитованных программ.

## 5. Примеры оформления ключевых блоков

### Hero
- ANO DPO: тёмный фон + крупный заголовок + бейдж лицензии +
  кнопка «Получить консультацию».
- Академия ДПО: hero с фоновым изображением + форма заявки справа
  (split-hero) + счётчик программ.
- Специалист: hero-карусель направлений (IT/языки/менеджмент).

### Курсы
- Карточка: иконка/превью + название + формат (очно/онлайн) +
  длительность в ак. часах + цена + кнопка «Подробнее/Записаться».
- Табы по категориям: «Рабочие профессии / Повышение квалификации /
  Профпереподготовка» (Академия ДПО, Профи).

### Отзывы
- Слайдер по 1–3 карточки, фото клиента, специальность, цитата, оценка 5★.
- У МФЮА и Академии ДПО — видеоотзывы на премиальных программах.

### Контакты
- Карта (Яндекс/Google), телефон, email, мессенджеры (WhatsApp/Telegram),
  форма заявки, режим работы, юридический адрес и реквизиты.

## 6. Ключевые выводы для нашего лендинга
1. **Доверие №1:** лицензия, № лицензии, ФИС ФРДО, документ гособразца —
   выносить в hero и блок преимуществ.
2. **Минимум трения в заявке:** 1–2 поля + телефон, быстрый ответ.
3. **Премиальная подача** через тёмно-синий + золотой акцент отличает от
   шаблонных «синих» конкурентов и усиливает восприятие статуса.
4. **Анимации — лёгкие:** частицы в hero, scroll-анимации, 3D-tilt карточек,
   счётчики, бесконечный marquee партнёров. Без ущерба скорости.
5. **Адаптив mobile-first:** >60% трафика ДПО — мобильный; форма и
   слайдеры обязаны работать корректно на 360px.
