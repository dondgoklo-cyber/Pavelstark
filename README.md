# Академия ДПО — Премиальный лендинг

Премиальный одностраничный лендинг для учебного центра дополнительного
профессионального образования (ДПО). Разработан по полному циклу: от анализа
конкурентов до финального кода.

## ✨ Особенности

- **Премиальный дизайн** — глубокий синий (#1A2332) + золотой (#FFD700),
  шрифты Playfair Display + Inter.
- **Mobile-first адаптив** — корректно работает от 360px до 1280px+.
- **Анимации** — GSAP (scroll, hero-таймлайн, счётчики), 3D-tilt карточек.
- **Particles.js** — лёгкий анимированный фон в hero-блоке.
- **Swiper.js** — слайдер отзывов + бесконечный marquee логотипов партнёров.
- **Доступность WCAG AA** — ARIA-роли, контраст, фокус-стили, клавиатура.
- **`prefers-reduced-motion`** — отключает тяжёлые анимации для комфортного просмотра.
- **Надёжные fallback'и** — контент виден даже если CDN-библиотеки не загрузились.
- **Валидация формы** — маска телефона РФ, inline-ошибки, согласие 152-ФЗ.

## 🚀 Запуск

Лендинг — статичный, не требует сборки. Откройте `index.html` в браузере
или поднимите локальный сервер:

```bash
# Python
python3 -m http.server 8000

# Node (npx)
npx serve
```

Затем откройте `http://localhost:8000`.

## 🎨 Блоки лендинга

1. **Header** — sticky, с бургер-меню на мобильном, телефон и CTA «Записаться».
2. **Hero** — particles-фон, заголовок, статистика со счётчиками.
3. **Направления** — табы (рабочие профессии / повышение квалификации / переподготовка).
4. **Преимущества** — 4 карточки с 3D-tilt и SVG-иконками.
5. **Курсы** — 6 карточек с тегами (Хит, Диплом, Премиум).
6. **Отзывы** — Swiper-слайдер с пагинацией.
7. **Партнёры** — бесконечный marquee логотипов.
8. **FAQ** — аккордеон с CSS-анимацией высоты.
9. **Форма заявки** — валидация + маска телефона + согласие на ПДн.
10. **Footer** — контакты, соцсети, документы.

## 🔧 Зависимости (CDN)

- [Particles.js 2.0.0](https://github.com/VincentGarreau/particles.js/) — фон hero
- [Swiper 11](https://swiperjs.com/) — слайдеры
- [Google Fonts](https://fonts.google.com/) — Playfair Display + Inter

## ⚠️ Дисклеймер

Все контактные данные (телефон, email, адрес, номер лицензии) являются
**демонстрационными**. Перед использованием в production замените их на
реальные и подключите форму к бэкенду (в `js/main.js`, функция `initForm`).
