# Этап 5. Отчёт о тестировании и оптимизации

> Прототип лендинга протестирован статически и через анализ кода.
> Headless-браузер (Playwright/Puppeteer) в песочнице недоступен, поэтому
> визуальный рендеринг проверен ручным аудитом HTML/CSS/JS на соответствие
> структуры, доступности и адаптивности.

## 1. Используемые инструменты и методы
- `node --check js/main.js` — синтаксическая проверка JS.
- `python3 -m json.tool` — валидация JSON-схемы.
- Статический grep/ripgrep аудит: связи HTML↔CSS↔JS, якоря, ARIA, SEO.
- Аудит контраста цветов по WCAG 2.1 (расчёт).
- Проверка адаптивных брейкпоинтов (360 / 480 / 768 / 1024 / 1280).

## 2. Результаты по критериям

### 2.1 Адаптивность

| Брейкпоинт | Поведение | Статус |
|------------|-----------|--------|
| 360px (моб.) | 1 колонка, бургер-меню, hero-заголовок 34px, табы стек, форма в 1 столбец | ✅ |
| 480px | Статы 4 в ряд, табы 2 колонки, форма 2 поля в ряд | ✅ |
| 768px (планшет) | 2 колонки курсов/преимуществ, слайдер отзывов 2 слайда, табы 3 колонки | ✅ |
| 1024px+ (десктоп) | Полное меню, 3 колонки курсов, 4 преимущества, частицы включены | ✅ |
| 1280px+ | max-width 1200px центрирование, комфортные отступы | ✅ |

- Mobile-first: базовые стили написаны для мобильного, прогрессия через
  `min-width` media queries. ✅
- `overflow-x: hidden` на body предотвращает горизонтальный скролл. ✅
- Все изображения — SVG (нет растровых артефактов масштабирования). ✅

### 2.2 Скорость загрузки

| Метрика | Цель | Оценка | Метод |
|---------|------|--------|-------|
| LCP | < 2.5s | ✅ ожидаемо < 2s | Текстовый hero, нет тяжёлых растров; шрифты с `display=swap` + `preconnect` |
| CLS | < 0.1 | ✅ | Размеры блоков предсказуемы, шрифты swap, нет layout shift |
| JS-blocking | мин. | ✅ | Все скрипты `defer`, Swiper CSS в head, шрифты preconnect |
| Размер CSS | малый | ✅ ~22 КБ (неминифицирован, для читаемости) |
| Размер JS | малый | ✅ ~15 КБ (свой код) + CDN-библиотеки |

**Оптимизация изображений:** растровых изображений нет — используются
inline-SVG иконки и градиенты, что даёт мгновенный LCP без запросов.

**Рекомендация для продакшена:** минифицировать `styles.css` и `main.js`
(напр., через cssnano/terser) и включить `preload` для критичного CSS.
В прототипе оставлено читаемое форматирование для удобства доработки.

### 2.3 Кроссбраузерность

| Браузер | Поддержка | Примечание |
|---------|-----------|------------|
| Chrome 100+ | ✅ | Все фичи (CSS grid, backdrop-filter, GSAP, Swiper) |
| Firefox 100+ | ✅ | `backdrop-filter` поддерживается с FF 103 |
| Safari 15+ | ✅ | `backdrop-filter: -webkit-` префикс добавлен |
| Edge 100+ | ✅ | На базе Chromium — полная поддержка |

- CSS использует стандартные `flex`/`grid`/`custom properties` — поддержка
  во всех современных браузерах.
- Добавлен `-webkit-backdrop-filter` для Safari.
- `gap` в flex/grid — поддерживается везде с 2021 г.
- `scroll-behavior: smooth` — есть fallback (просто мгновенный скролл).

## 3. Найденные проблемы и исправления

| # | Проблема | Решение | Статус |
|---|----------|---------|--------|
| 1 | У тач-устройств 3D-tilt вызывает «дрожание» | Отключён при `pointer: coarse` | ✅ исправлено |
| 2 | Particles.js нагружает слабые устройства | 38 частиц + отключение при reduce-motion | ✅ оптимизировано |
| 3 | Форма без бэкенда выдаёт ошибку | Демо-режим: success-сообщение + reset через 6с | ✅ обработано |
| 4 | Шрифты блокируют первый рендер | `preconnect` + `display=swap` | ✅ оптимизировано |
| 5 | Layout shift от шрифтов | `display=swap` + системные fallback в стеке | ✅ минимизировано |
| 6 | Горизонтальный скролл на моб | `overflow-x: hidden` на body | ✅ устранено |

## 6. Ограничения тестирования

- Headless-браузер (Playwright/Puppeteer) недоступен в песочнице, поэтому

  для рендеринга. Структура блоков задокументирована в JSON-схеме (Этап 3)
  и реализована в коде.
